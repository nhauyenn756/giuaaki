GÓC HỌC TẬP

HTML & JAVASCRIPT

Tìm hiểu cấu trúc HTML, thành phần thẻ HTML và cách sử dụng JavaScript trong phát triển web.

01. CẤU TRÚC TỔNG QUAN HTML

HTML (HyperText Markup Language) là ngôn ngữ đánh dấu siêu văn bản, dùng để xây dựng cấu trúc và nội dung của trang web.

Cấu trúc cơ bản của một tài liệu HTML

<!DOCTYPE html>
<html lang="vi">

    <head>
        <meta charset="UTF-8">
        <title>Trang web</title>
    </head>

    <body>
        <h1>Xin chào!</h1>
        <p>Đây là trang web của tôi.</p>
    </body>

</html>

Ý nghĩa các thành phần

Thành phần Chức năng
DOCTYPE Khai báo tài liệu HTML5.
html Phần tử gốc của tài liệu HTML.
head Chứa thông tin cấu hình trang web.
meta Khai báo thông tin về tài liệu.
title Đặt tiêu đề trên tab trình duyệt.
body Chứa nội dung hiển thị trên trang web.

02. CÁC THÀNH PHẦN CỦA THẺ HTML

Một phần tử HTML thường bao gồm thẻ mở, nội dung, thẻ đóng và có thể có các thuộc tính.

Ví dụ minh họa

<p class="intro">
    Xin chào các bạn!
</p>
Khái niệm Giải thích Ví dụ
Tag Thẻ HTML. <p>
Element Phần tử HTML hoàn chỉnh. <p>Hello</p>
Attribute Thuộc tính bổ sung thông tin. class="intro"
Content Nội dung bên trong phần tử. Xin chào các bạn!
Lưu ý: Một số thẻ HTML là thẻ rỗng, ví dụ như img và br, không cần thẻ đóng.

03. INTERNAL JAVASCRIPT

Internal JavaScript là cách viết mã JavaScript trực tiếp bên trong tài liệu HTML thông qua thẻ script.

Ví dụ minh họa

<button onclick="showMessage()">
    Click vào đây
</button>

<script>
    function showMessage() {
        alert("Xin chào!");
    }
</script>

Thực hành trực tiếp

Nhấn nút bên dưới để kiểm tra Internal JavaScript.

04. EXTERNAL JAVASCRIPT

External JavaScript là cách viết mã JavaScript trong một file riêng có phần mở rộng .js, sau đó liên kết với tài liệu HTML.

Cấu trúc thư mục

project/
│
├── index.html
│
└── js/
    └── external.js

File HTML

<button onclick="externalJS()">
    Click vào đây
</button>

<script src="js/external.js"></script>

File external.js

function externalJS() {
    alert("Đây là External JavaScript!");
}

Nhấn nút bên dưới để kiểm tra External JavaScript.

05. SO SÁNH INTERNAL VÀ EXTERNAL JAVASCRIPT

Tiêu chí Internal JS External JS
Vị trí Trong file HTML. File .js riêng.
Cách khai báo Thẻ script. script src.
Tái sử dụng Khó hơn. Dễ dàng.
Quản lý Phù hợp code nhỏ. Dễ bảo trì và quản lý.
Ứng dụng Trang web đơn giản. Dự án nhiều trang.
Kết luận: External JavaScript phù hợp với các dự án lớn vì giúp tách biệt mã nguồn, dễ tái sử dụng và bảo trì.
