GÓC HỌC TẬP

CSS - CASCADING STYLE SHEETS

Tìm hiểu cú pháp, ý nghĩa và ba cách sử dụng CSS trong thiết kế website.

01. TỔNG QUAN VỀ CSS

CSS (Cascading Style Sheets) là ngôn ngữ định kiểu được sử dụng để thiết kế giao diện và trình bày các thành phần HTML.

Cú pháp CSS

selector {
    property: value;
}
Thành phần Ý nghĩa
Selector Bộ chọn phần tử HTML cần định dạng.
Property Thuộc tính cần thay đổi.
Value Giá trị của thuộc tính.
Declaration Cặp thuộc tính và giá trị.

02. INLINE CSS - CSS NỘI TUYẾN

Inline CSS là cách viết CSS trực tiếp trong thẻ HTML thông qua thuộc tính style.

Cú pháp minh họa

<h2 style="color: blue; font-size: 28px;">
    Xin chào các bạn!
</h2>

Kết quả hiển thị

Xin chào các bạn!

Được định dạng trực tiếp bằng thuộc tính style.

Ưu điểm

Dễ sử dụng, áp dụng nhanh cho một phần tử.

Nhược điểm

Khó tái sử dụng và bảo trì khi mã nguồn lớn.

03. INTERNAL CSS - CSS NỘI BỘ

Internal CSS là cách viết CSS trong thẻ style, thường đặt bên trong phần head của HTML.

Cú pháp minh họa

<head>
    <style>
        .internal-example {
            color: green;
            font-size: 23px;
            text-align: center;
        }
    </style>
</head>

Kết quả hiển thị

Xin chào các bạn!

Được định dạng bởi thẻ style trong head.

Ưu điểm

Có thể định dạng nhiều phần tử trong cùng một trang.

Nhược điểm

Khó dùng chung CSS cho nhiều trang HTML.

04. EXTERNAL CSS - CSS BÊN NGOÀI

External CSS là cách viết CSS trong một file riêng có phần mở rộng .css, sau đó liên kết với tài liệu HTML.

Cấu trúc thư mục

project/
│
├── style.html
│
└── css/
    └── style-demo.css

Liên kết file CSS trong HTML

<link rel="stylesheet"
      href="css/style-demo.css">

Nội dung file style-demo.css

.external-example {
    color: #a044a4;
    font-size: 23px;
    text-align: center;
    background-color: #f7edfa;
    padding: 18px;
}

Kết quả hiển thị

Xin chào các bạn!

Được định dạng từ file CSS bên ngoài.

Ưu điểm

Dễ tái sử dụng, quản lý và bảo trì nhiều trang.

Nhược điểm

Cần quản lý file và đường dẫn chính xác.

05. SO SÁNH CÁC LOẠI STYLE

Tiêu chí Inline Internal External
Vị trí Trong thẻ HTML Thẻ style File CSS riêng
Phạm vi Một phần tử Một trang Nhiều trang
Tái sử dụng Thấp Trung bình Cao
Bảo trì Khó Trung bình Dễ

KẾT LUẬN

Inline CSS phù hợp để định dạng nhanh một phần tử. Internal CSS phù hợp với website đơn giản có một trang. External CSS phù hợp với website có nhiều trang, giúp mã nguồn dễ quản lý, tái sử dụng và bảo trì.
