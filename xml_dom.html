XML & DOM

Tìm hiểu cấu trúc XML và cách sử dụng JavaScript DOM để tạo bảng dữ liệu HTML.

01. CẤU TRÚC TỔNG QUAN XML

XML (Extensible Markup Language) là ngôn ngữ đánh dấu mở rộng được sử dụng để lưu trữ và trao đổi dữ liệu có cấu trúc.

Ví dụ cấu trúc XML

<?xml version="1.0" encoding="UTF-8"?>

<students>

    <student id="SV001">
        <name>Nguyen Nha Uyen</name>
        <class>K24416</class>
        <email>uyen@gmail.com</email>
    </student>

    <student id="SV002">
        <name>Tran Van A</name>
        <class>K24417</class>
        <email>a@gmail.com</email>
    </student>

</students>

Các thành phần của XML

Thành phần Ý nghĩa
XML Declaration Khai báo phiên bản và bảng mã.
Root Element Phần tử gốc của tài liệu XML.
Element Phần tử chứa dữ liệu.
Attribute Thuộc tính bổ sung thông tin.
Text Nội dung văn bản của phần tử.

02. TÌM HIỂU DOM

DOM (Document Object Model) là mô hình đối tượng tài liệu, biểu diễn XML hoặc HTML dưới dạng cây các Node.

Các phương thức DOM thường sử dụng

Phương thức Chức năng
getElementsByTagName() Lấy các phần tử theo tên thẻ.
getAttribute() Lấy giá trị thuộc tính.
createElement() Tạo phần tử HTML mới.
textContent Đọc hoặc gán nội dung văn bản.
appendChild() Thêm phần tử con vào phần tử cha.

03. THỰC HÀNH TẠO TABLE BẰNG DOM

Sử dụng JavaScript DOM để đọc danh sách sinh viên từ dữ liệu XML và tạo Table HTML tự động.

Dữ liệu XML đầu vào

<students>
    <student id="SV001">
        <name>Nguyen Nha Uyen</name>
        <class>K24416</class>
        <email>uyen@gmail.com</email>
    </student>
</students>

Thực hành trực tiếp

Nhấn nút bên dưới để đọc dữ liệu XML và tạo bảng HTML bằng DOM.

Lưu ý: Table không được viết sẵn các hàng dữ liệu trong HTML. JavaScript sẽ tự tạo các phần tử Table, TR, TH và TD.

04. QUY TRÌNH TẠO TABLE BẰNG DOM

  1. Đọc dữ liệu XML.
  2. Sử dụng DOM để phân tích XML.
  3. Lấy danh sách các phần tử student.
  4. Tạo phần tử table.
  5. Tạo hàng tiêu đề bằng tr và th.
  6. Tạo các hàng dữ liệu bằng tr và td.
  7. Sử dụng appendChild() để ghép các phần tử.
  8. Hiển thị Table lên trang web.
